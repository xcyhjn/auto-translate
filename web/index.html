                    展开字段说明
                    

                    
工作流
选择语言管线预设，会更新源语言、目标语言、ASR 模型、提示词、数据集和参考层样式。例：俄文视频选 ru_to_zh_default。

                    
字幕模式
target_only 只输出中文；bilingual_source_reference 输出中文加源语参考层；source_review 用于源语校对。

                    
参考层标签
用于源语文件名和参考层身份。俄文用 ru，英文用 en。

                    
提示词 Profile
控制翻译风格和语言规则。俄译中建议 ru_zh_natural_subtitle。

                    
数据集 Profile
加载术语、QA 样例、ASR 易混词和风格例子。俄译中建议 ru_zh/general。

                    
俄文范例
ru -> zh-Hans，large-v3，Huiwen-HKHei，32，80，4，1.2，full_split。
