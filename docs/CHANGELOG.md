#### 新功能

- 增加更完整的英文参考层分割策略：优先使用 ASR word timing、标点、停顿与语义边界进行分段，并保留无法安全拆分时的显式多行回退。
- 增加双语 ASS 多行参考联动：只有 `EnglishSmall` 实际包含 `\N` 时才抬升同时间段中文字幕。
- 增加可配置中文字距、参考层完整分割模式，以及更醒目的中文字幕颜色、描边和阴影默认值。
- 增加实体注册表、英文到中文的正式数据目录和 VS Code ASS/SSA 双语语法高亮配置。
- 增加 GPU/CPU ASR 降级回归测试，以及音频 artifact 移动语义测试。

#### 改进

- 扩展 CUDA 运行库发现：支持环境变量、已安装 CUDA 目录与 `ctranslate2` 本地运行库目录。
- ASR 遇到显存或内存分配失败时，依次尝试低 beam、CUDA INT8、CPU INT8 等更低资源路径。
- 最终 ASS QA 新增参考层省略号阻断和英文单行长度警告。
- CLI 改为按实际子命令惰性加载依赖；仅查看帮助或执行 dry-run 时不再初始化 ASR、OpenAI 或机器学习依赖。
- UI 状态和错误日志统一归入 `runtime/`，根目录不再承载运行态文件。
- `yt-dlp` 用户配置同步支持 `remote_components`。
- 正式项目文档、JSON 规则数据与工具配置不再被过宽的 ignore 规则隐藏。

### 用户可见摘要

#### 新增与改进

- **双语字幕更完整**：英文参考字幕会优先按自然语义与真实词级时间拆分，不再为了行宽直接截断句子。
- **字幕布局更稳定**：英文确实分成多行时，中文字幕才会自动上移，减少双语重叠。
- **识别更抗显存不足**：GPU 资源不足时会自动尝试更节省显存的配置，并可继续回退到 CPU。
- **人工校对更方便**：新增 VS Code ASS/SSA 双语语法高亮配置，便于检查样式、双语层和换行符。
- **项目目录更清爽**：运行日志和状态文件统一放入 runtime，历史试跑文件不再堆积在根目录。

#### 修复

- 修复部分长英文参考字幕被省略号截断的问题。
- 修复重复生成两份相同音频文件的问题。
- 修复重烧录时字幕样式与当前配置不一致的问题。

#### 当前限制

- 真实视频的最终效果仍需要人工检查，特别是极长英文、多行中文字幕和不同分辨率下的布局。
- 旧项目中已经存在的重复 WAV 未自动删除，可在确认备份后单独整理。
